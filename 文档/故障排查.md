# 故障排查

## `npm run setup` 无法创建 Qwen 环境或下载模型

默认 Qwen 环境需要本地 Python 3.10+，建议使用 Python 3.12。`npm run doctor` 会显示当前可用的 Python 版本。若默认的 `python3` 不符合要求，可明确指定本地解释器：

```bash
QWEN_EXPERIMENT_PYTHON="/opt/homebrew/opt/python@3.12/bin/python3.12" npm run setup
```

这只会创建 `实验/qwen-asr/.venv/` 并下载官方 Qwen 模型，不会读取或上传媒体。Windows 可运行本地 CPU 代码路径，但仍须完成实机验证。

Windows 可使用本地 CPU 运行代码路径，但尚未完成实机验证。部署和冒烟检查见
[Windows Qwen 本地转录](../Windows/Qwen本地转录.md)；在该检查通过前，不得把
Windows 标为已支持。

## 模型下载中断

重新运行 `npm run setup`。安装器只在本地模型目录已有 `config.json` 时跳过对应模型；若下载器报告损坏文件，保留错误记录，再按报错路径清理该模型目录后重试。

## Whisper.cpp 回退安装失败

默认流程不需要编译 Whisper.cpp。只有明确调用 `npm run whisper:setup` 时才需要 Apple 命令行开发工具：

```bash
xcode-select --install
npm run whisper:setup
```

## Windows 中文转录出现乱码或超长时间码

不要直接重跑整片。先检查原始 Whisper JSON 和标准化逐字稿是否出现 `U+FFFD`，以及是否有单条字幕跨越 30 秒以上。Whisper.cpp 1.5.5 的 Windows `main.exe` 在启用 DTW token 时间码时可能触发这一问题。

Windows 应禁用 DTW，并使用句段字幕（每段最多 128 tokens）。用原片开头、中段、结尾各 30 秒验证标准化字幕为零乱码、零无效时间码、零超长字幕后，才能重新转录整片。保留失败的原始 JSON 和草稿以便复盘，不要覆盖或删除它们。

## 转录提示找不到输入文件

从仓库根目录运行命令，并给中文或带空格的路径加双引号。直播原片应位于 `输入/媒体素材/直播录像/`。

## Studio 找不到直播源

先完成 `npm run clips:review -- prepare ...`。该步骤会将原片链接或复制到 Remotion 的本地生成目录，原片本身不会修改。
