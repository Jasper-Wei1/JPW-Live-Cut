# 本地语音转录

直播原片默认经本地 `Qwen3-ASR-0.6B + Qwen3-ForcedAligner-0.6B` 转为带时间码的逐字稿：

```text
直播录像 -> 16 kHz 单声道 WAV -> Qwen3 ASR -> ForcedAligner -> 标准化逐字稿 JSON
```

音频不会上传到云端语音服务。模型、Python 环境、缓存和运行结果都在仓库相对路径中；正常转录阶段会启用离线模式。直播没有正式口播稿，原声和带时间码逐字稿是内容真源。只能依据原声修正明确的错字、专名和短小歧义；听不清的内容必须记录在 `ambiguities`，不得为了流畅改写原话。

默认模型合计约 3.5 GB。当前验证平台为 macOS MPS，使用 `float16`、120 秒连续分段、单批推理；每段保留 ForcedAligner 原始时间戳、来源和精度标记。运行前会以本地 `ffprobe` 读取原片时长，若提取音频与媒体时长相差超过 1 秒则拒绝生成逐字稿。草稿结果放在 `工作区/数据/草稿/`，包括标准化 `schemaVersion: 1` 逐字稿、原始 Qwen 输出和性能记录。

完整直播只运行一次 Qwen 转录。经 Studio 批准的连续切片复用这份原始 Qwen 时间轴并重映射到派生母版，不重新运行语音识别。重映射不会改变文字和时间戳来源；需要人工确认的内容会保留为疑点。

Whisper.cpp 只保留为显式回退：`npm run whisper:transcribe`。它不是默认路径，也不能被用来标记 Qwen 字幕或作为 Qwen 质量结论。
